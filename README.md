
Cette application frontend a été développée avec **React JS** et stylisée grâce à **Chakra UI** pour une interface utilisateur moderne et responsive.  
Elle utilise **Axios** pour envoyer des requêtes HTTP vers l’API d’**AssemblyAI**, permettant :

- l’envoi d’enregistrements audio,
- le suivi en temps réel du traitement,
- la récupération et l’affichage des résultats d’analyse (ex. : analyse de sentiment, détection d'entités…).

L’architecture repose sur une **logique modulaire** : chaque fonctionnalité d’analyse est gérée dans un **composant React dédié**, ce qui rend l’application maintenable et évolutive.
